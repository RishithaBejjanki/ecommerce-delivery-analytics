# Power BI dashboard: build guide

Dashboard name: **Delivery Performance**. Three pages, each answering one question.
Built on the star schema in `data/processed/` (generated by `python scripts/run_pipeline.py`).

## 1. Load and model (≈15 min)
1. **Get data → Text/CSV**, load all six files from `data/processed/`:
   `fact_orders`, `fact_order_items`, `dim_customer`, `dim_seller`, `dim_product`, `dim_date`.
2. In **Power Query**, check types:
   - `purchased_at`, `approved_at`, `shipped_at`, `delivered_at` → Date/Time
   - `purchase_date`, `promised_date`, `dim_date[date]` → Date
   - `is_late`, `seller_missed_sla`, `same_state`, `in_analysis` → True/False
3. **Model view:** create these relationships (all many-to-one, single direction):
   | From | To |
   |---|---|
   | fact_orders[customer_id] | dim_customer[customer_id] |
   | fact_orders[primary_seller_id] | dim_seller[seller_id] |
   | fact_orders[purchase_date] | dim_date[date] |
   | fact_order_items[order_id] | fact_orders[order_id] |
   | fact_order_items[product_id] | dim_product[product_id] |
4. Mark `dim_date` as a date table (Table tools → Mark as date table → `date`).
5. Add the measures in [`dax_measures.md`](dax_measures.md).
6. **Filters pane → Filters on all pages:** `fact_orders[in_analysis]` = True.

## 2. Pages

### Page 1: Overview ("How are we doing?")
- **KPI cards:** Orders · Late % · Avg Delivery Days · Avg Review · One-Star %
- **Line chart:** `dim_date[year_month]` × `Late %`, with an average line (Analytics pane → Average line)
- **Clustered column:** `Lateness Bucket` × `Avg Review` (tooltip: `One-Star %`)
- **Slicers (top row):** `dim_date[year_month]` range, `dim_customer[region]`
- Text box headline: *"Late orders are 6.8% of deliveries but 37% of 1-star reviews."*

### Page 2: Root cause ("Where does the time go?")
- **Stacked bar:** values `Avg Handling Days`, `Avg Transit Days`; axis `fact_orders[is_late]`
- **Clustered bar:** `seller_missed_sla` × `Late %`
- **Filled map or bar chart:** `dim_customer[state]` × `Late %`, sorted by `Late Orders`
- **Table:** state, Orders, Late %, Late Orders, Share of Late Orders (conditional formatting on Late %)
- **Clustered bar:** `same_state` × `Late %`

### Page 3: Seller watchlist ("Who do we call?")
- **Table:** `dim_seller[seller_id]`, `dim_seller[state]`, Orders, Late Orders, Late %, Seller Missed SLA %,
  Avg Handling Days, Avg Review, GMV
  - Visual filter: Orders ≥ 50 and Late % ≥ 12%
  - Conditional formatting: data bars on Late Orders; red background where Seller Missed SLA % ≥ 20%
- **Scatter:** x = Seller Missed SLA %, y = Late %, size = Orders, one dot per seller.
  Top-right is seller-driven, top-left is route-driven.
- **Drill-through:** right-click a seller → page showing that seller's monthly Late % and their worst customer states.

## 3. Design
- One accent colour for *late / problem* (orange `#eb6834`), one for *normal* (blue `#2a78d6`), grey for context.
- Every page title is a finding, not a label ("Carrier transit drives late orders", not "Stage analysis").
- Format: Late % and One-Star % as percentage with 1 decimal; days with 1 decimal.

## 4. Publish to the repo
1. **File → Export → Export to PDF** → save as `powerbi/delivery_performance.pdf`.
2. Screenshot each page (Win + Shift + S) → save as `powerbi/screenshots/page1_overview.png`,
   `page2_root_cause.png`, `page3_watchlist.png`.
3. Save the report as `powerbi/delivery_performance.pbix`. It stays small because it holds the
   aggregated model only (~10 MB). If it goes over 25 MB, upload it with GitHub Desktop rather than the browser.
4. Add the screenshots to the main README under "Dashboard":
   ```markdown
   ![Overview](powerbi/screenshots/page1_overview.png)
   ```
